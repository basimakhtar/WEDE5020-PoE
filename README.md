## Project Overview

This project builds a professional, multi-page website for **VoltStream Plumbing & Electrical (Pty) Ltd**, a (fictional but realistic) family-owned plumbing and electrical services company based in Johannesburg, South Africa. The company serves homeowners, body corporates and small businesses in Sandton, Randburg, Fourways, Bryanston and Midrand.

The website follows a three-part development journey:

1. **Part 1 — Building the Foundation:** project planning, research, content sourcing and the semantic HTML structure of the site (this submission).
2. **Part 2 — Designing the Visuals:** CSS styling, responsive design and user-experience optimisation.
3. **Part 3 — Adding Functionality and SEO:** JavaScript interactivity, client-side form validation, SEO refinements and embedded external services.

A second, alternative project proposal for **Paws of Hope Animal Shelter** (NPO) was prepared alongside the VoltStream proposal. Both proposals are documented in `docs/Website-Project-Proposal.docx`. VoltStream Plumbing & Electrical was selected as the organisation to build for.

## Key Features and Functionality

**Part 1 (delivered):**
- 5 linked HTML pages with a consistent header, navigation and footer.
- Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `footer`, `address`, `figure`-style image usage, `table`, `form`, `fieldset`).
- SEO groundwork: `meta description`, keywords, meaningful page titles, descriptive alt text on every image.
- Enquiry form (quote request) and quick-contact form.
- Contact page with **two branch locations** (Sandton head office and Randburg branch), each with an embedded Google Map.
- Original SVG assets (logo, team avatars) and web-optimised, legally sourced photos.
- Git version control with descriptive commit messages and a changelog.

**Planned for Part 2:**
- Full CSS stylesheet (colour scheme: deep blue, bright orange, off-white), typography hierarchy, responsive mobile layout, hover states and accessibility improvements.

**Planned for Part 3:**
- JavaScript form validation, interactive elements and animations, embedded YouTube/how-to content, final SEO pass and sitemap/analytics readiness.
