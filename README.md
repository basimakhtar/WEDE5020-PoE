Project Overview

This project is a website for VoltStream Plumbing and Electrical (Pty) Ltd, a small plumbing and electrical business in Johannesburg. Two proposals were written, one for VoltStream and one for Paws of Hope Animal Shelter, and VoltStream was chosen.

Part 1: planning, research and the HTML structure.
Part 2: the CSS styling and responsive design.
Part 3: the JavaScript functionality, the SEO work and the deployment.

The site is live at:

https://basimakhtar.github.io/WEDE5020-PoE/


Website Goals and Objectives

- 20 or more quote requests a month by month 3.
- 60% of enquiries turning into bookings.
- 10 or more emergency call-outs a month from the website.
- First-page Google results for five local search terms by December 2026.
- Home page bounce rate under 45%.


Key Features and Functionality

- Five linked HTML pages with one shared navigation menu.
- A shared stylesheet with the brand colours, a mobile-first layout and breakpoints at 40em and 64em.
- Responsive images with srcset and sizes.
- A recent-work gallery with filter buttons and a lightbox.
- Tabs on the about page and modals with the team members' full bios.
- A live search filter and a FAQ accordion on the services page.
- Interactive Leaflet maps on the contact page, one per branch.
- JavaScript validation on both forms, with error messages next to each field.
- The enquiry form fetches pricing data and shows a cost estimate and availability note without reloading the page.
- The contact form compiles the message into an email addressed to info@voltstream.co.za.
- All the interactivity is plain JavaScript rather than jQuery, which keeps the pages light.
- SEO: meta descriptions, canonical links, Open Graph tags, JSON-LD business data, robots.txt and sitemap.xml.
- Off-page SEO: social media links in the footer and a Google Business Profile, so the pages can earn backlinks and local searches find the business.
- Deployed free of charge on GitHub Pages.
